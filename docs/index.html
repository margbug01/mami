Talk or translate, right where you type.

Tap Right Alt and say it: tidy text lands in the box you are typing in. Select text and a small button translates it, or press Alt T to replace it in place. Mami is a Windows tray app that uses the models and API keys you already have.

Speak instead of typing

Tap, talk, tap
Right Alt by default, or any key, shortcut or media button. Esc cancels. With Qwen 3.1 streaming, the text is ready about half a second after you stop.
Cleaned up, not rewritten
Fillers and "no wait, I mean" are dropped. Questions are not answered and nothing is translated behind your back. Four levels, from off to structured.
Learns your words
Add names and product names to the vocabulary. Fix a misheard word twice and Mami fixes it for you from then on. Only sound-alike fixes are learned.

Built to stay out of the way

Input boxes only
Web pages and documents are left alone. Before showing anything, Mami asks Windows whether the focus is an editable field.
Keeps your selection
The button and the card never take focus, and your clipboard is put back after every translation.
Safe in terminals
In Windows Terminal Mami sends no keystrokes, so the program you are running never gets a surprise Ctrl+C.
Your model, your key
Pick a provider and the endpoint fills itself in; keys are encrypted with Windows DPAPI and remembered per endpoint. Audio and text go only where you send them.

Make it yours

Light and dark themes, nine interface languages, twenty target languages, extra instructions for style and terminology, and a history page that shows how much typing you saved.

Get started

  1. Download the installer from the releases page and run it. Mami opens its settings the first time.
  2. Translation starts on bilibili's free endpoint, which needs no key. For daily use, pick a provider below and paste your key.
  3. For voice, turn it on under Dictation, add a speech key and a polish key, then tap Right Alt anywhere you type.
  4. Select text in any input box. Press Alt T to translate and replace, or Alt Shift T to only see the card.
